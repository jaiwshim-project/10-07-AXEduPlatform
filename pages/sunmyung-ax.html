  • 1️⃣ AI와 생성형 AI가 무엇인지 쉽게 이해하게 합니다

  • 4️⃣ Gemini 딥리서치로 조사와 비교 분석을 경험하게 합니다
  • 5️⃣ 나노바나나와 NotebookLM을 활용해 이미지와 자료 기반 학습 결과물을 만들어보게 합니다

모듈 2: ChatGPT 3가지 사용 모드

ChatGPT는 대화로 생각을 정리하고, 이미지로 아이디어를 시각화하며, 프로젝트로 하나의 일을 계속 발전시키는 AI 작업 파트너입니다. 3가지 사용 모드로 구분해 체계적으로 학습합니다.

1️⃣ 대화형 ChatGPT (40분)

질문하고 답변받는 가장 기본적인 사용 방식. AI 비서처럼 대화하며 생각, 글, 자료, 아이디어를 정리합니다.

  • 개념 설명: 생성형 AI를 초등학생도 이해할 수 있게 설명받기
  • 요약: 긴 글을 5줄로 요약, 핵심 키워드 추출
  • 글쓰기: 교육 안내문, 이메일, 블로그 초안 작성
  • 아이디어 도출: 교육 제목 20개 추천, 콘텐츠 아이디어 생성
  • 표 작성: AI 도구 비교표, 체크리스트 만들기
  • 역할극: 고객 상담, 면접 연습
2️⃣ 이미지 생성형 ChatGPT (30분)

말로 설명한 내용을 이미지로 만들어주는 기능. 글로 그림을 주문하듯이 포스터, 카드뉴스, 표지를 제작합니다.

  • 교육 포스터: 'AI 첫걸음 과정' 홍보 이미지 제작
  • 카드뉴스: SNS용 이미지 생성 (예: AI 초보자 5가지 활용법)
  • 전자책 표지: 워크북·교재 표지 시안
  • 인포그래픽: 개념 설명용 시각자료 (예: AI 교육 4단계 로드맵)
  • 이미지 프롬프트 공식: 대상 + 장면 + 스타일 + 색상 + 비율 + 용도
3️⃣ 프로젝트형 ChatGPT (30분)

하나의 주제를 별도의 작업 공간처럼 관리하는 방식. AI와 함께 일하는 전용 작업방에서 여러 결과물을 연결해 완성합니다.

  • 주제별 작업 관리: 'AI 교육 과정 개발' 프로젝트 생성
  • 자료 축적: 교육안, 홍보문, FAQ를 하나의 프로젝트에 모아 관리
  • 맥락 유지: 정한 방향을 유지하며 후속 작업 진행
  • 결과물 발전: 초안 → 수정 → 확장 → 최종안 개발
  • 업무 패키지화: 제안서, 홍보문, 이미지, 설문지를 하나의 흐름으로 제작
4️⃣ 통합 실습 (10분)

주제: AI 첫걸음 교육 홍보 패키지 만들기

  • 대화형으로 교육 소개문 작성 → 수강 대상·기대 효과 정리
  • 이미지 생성형으로 A4 세로형 홍보 포스터 제작
  • 프로젝트형으로 전체 패키지를 하나의 구조로 관리
  • 최종 결과: 홍보문 + 포스터 + 프로젝트 구조표
산출물: 요약문, 안내문, 제목 10개 (대화형), AI 교육 포스터 이미지 (이미지형), 프로젝트 구조표 (프로젝트형), 나의 활용 시나리오

💡 초보자 핵심 메시지: ChatGPT는 초보자 과정에서 세 가지 방식으로 배웁니다. 대화형으로 생각을 정리하고, 이미지 생성형으로 시각자료를 만들며, 프로젝트형으로 여러 결과물을 연결해 완성합니다. 이 세 가지를 익히면 ChatGPT를 단순한 질문 도구가 아니라, 생각 정리·시각자료 제작·업무 프로젝트 완성을 돕는 AI 파트너로 활용할 수 있습니다.

모듈 2: ChatGPT 대화형 실무

ChatGPT 대화 기능을 활용해 실무 문서와 콘텐츠를 작성합니다. 단순 질문보다 "업무용 결과물 작성"에 초점을 둡니다.

  • 이메일 작성: 안내 메일, 제안 메일, 감사 메일
  • 보고서 작성: 요약 보고서, 회의 보고서, 기획 보고서

모듈 3: ChatGPT 이미지 생성 실무

ChatGPT 이미지 생성을 활용해 실무에 필요한 시각자료를 만듭니다. 목적이 분명한 홍보 이미지 제작에 초점을 둡니다.

모듈 9: 클로드코드로 2시간만에 만드는 플랫폼 개발 실습

클로드코드(Claude Code)를 활용해 AI와 대화하며 실제 작동하는 웹 플랫폼을 개발합니다. 코딩 경험이 없어도 AI와 협업하여 2시간 안에 플랫폼을 완성할 수 있습니다.

💻 클로드코드(Claude Code)란?

Anthropic에서 만든 AI 코딩 도우미. 자연어로 대화하며 코드를 작성하고, 파일을 생성하고, 웹사이트를 만들 수 있습니다. 코딩을 모르는 사람도 AI와 협업하여 플랫폼을 개발할 수 있는 혁신적인 도구입니다.

1️⃣ 플랫폼 개발 기초 (30분)
  • 클로드코드 설치 및 환경 설정
  • AI와 대화하며 코딩하는 방법 이해
  • HTML, CSS, JavaScript 기본 구조 체험
  • 간단한 웹페이지 만들어보기
  • 클로드에게 명령하는 프롬프트 패턴
2️⃣ 프로필 플랫폼 개발 실습 (60분)

주제: 자신을 소개하는 개인 프로필 웹사이트 개발

  • 클로드에게 "내 소개 웹사이트를 만들어줘" 요청하기
  • 프로필 섹션: 이름, 직업, 소개문, 프로필 사진
  • 경력 섹션: 경력 사항, 주요 성과, 스킬
  • 포트폴리오 섹션: 프로젝트, 작업물, 링크
  • 연락처 섹션: 이메일, SNS 링크, 연락 양식
  • 반응형 디자인: 모바일·태블릿·데스크탑 대응
  • 스타일 커스터마이징: 색상, 폰트, 레이아웃 변경
3️⃣ 프롬프트 예시
1단계 프롬프트:
"내 소개를 담은 개인 프로필 웹사이트를 만들어줘. HTML, CSS, JavaScript를 사용하고, 프로필 섹션, 경력 섹션, 포트폴리오 섹션, 연락처 섹션으로 구성해줘. 깔끔하고 전문적인 디자인으로 만들어줘."
2단계 프롬프트:
"프로필 섹션에 내 정보를 넣어줘. 이름: 홍길동, 직업: AI 교육 전문가, 소개문: AI를 활용한 업무 혁신 교육을 진행하고 있습니다."
3단계 프롬프트:
"색상 테마를 파란색 계열로 바꾸고, 폰트를 좀 더 모던하게 변경해줘. 모바일에서도 잘 보이도록 반응형으로 만들어줘."
4️⃣ 심화: 기능 추가 (30분)
  • 다크모드/라이트모드 토글 기능
  • 부드러운 스크롤 애니메이션
  • 프로필 이미지 호버 효과
  • 연락 양식 유효성 검사
  • 소셜 미디어 아이콘 링크
  • 간단한 블로그 섹션 추가
산출물: 개인 프로필 웹사이트 (HTML, CSS, JS 파일), 배포 가능한 완성된 플랫폼, 클로드코드 활용 프롬프트 모음

💡 핵심 포인트: 코딩을 모르는 사람도 클로드코드와 대화하며 2시간 안에 실제 작동하는 웹사이트를 만들 수 있습니다. 이는 단순한 체험이 아니라, AI와 협업하는 새로운 개발 방식을 경험하는 과정입니다.
