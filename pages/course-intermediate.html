💡 중급 과정의 핵심

초급 과정은 AI로 문서·콘텐츠·이미지·리서치 결과물을 만드는 과정입니다.
중급 과정은 클로드코드로 실제 풀스택 플랫폼, 에이전트, 스킬, 옵시디언 위키를 만드는 과정입니다.

🎯 초급 과정과 중급 과정의 차이

초급은 "AI로 무엇을 만들까?", 중급은 "AI와 함께 어떻게 시스템을 만들까?"

구분 초급 과정 중급 과정
핵심 목표 AI로 실무 산출물 제작 AI로 실제 플랫폼 개발
중심 도구 ChatGPT, Gemini, 나노바나나, NotebookLM Claude Code, GitHub, Supabase, Obsidian
학습 방식 프롬프트 실습 바이브코딩 실습
결과물 문서, 이미지, 리서치, FAQ 풀스택 웹앱, 에이전트, 스킬, 위키
적용 범위 개인 업무 서비스·플랫폼·자동화 시스템
핵심 질문 AI로 무엇을 만들까? AI와 함께 어떻게 시스템을 만들까?
최종 산출물 업무 산출물 패키지 작동하는 AI 플랫폼 MVP

📚 14시간 커리큘럼 (8개 모듈)

모듈 1
클로드코드와 바이브코딩 이해
⏱️ 1시간
클로드코드의 역할, 바이브코딩 개념, 프론트엔드·백엔드·DB 관계, 파일 구조 이해
모듈 2
풀스택 플랫폼 구조 설계
⏱️ 2시간
플랫폼 목적 정의, 화면 구조 설계, 데이터 구조 설계, MVP 범위 결정
모듈 3
클로드코드로 풀스택 MVP 만들기
⏱️ 3시간
프로젝트 생성, 화면 컴포넌트, 입력폼, 데이터 저장, 목록 화면, 관리자 대시보드
모듈 4
에이전트 설계와 개발
⏱️ 2시간
에이전트 개념, 역할·입력·출력 구조, AI 커리큘럼 코치 에이전트 설계 및 UI 개발
모듈 5
스킬 개발 실습
⏱️ 2시간
스킬 개념, SKILL.md 작성, 플랫폼 페이지 생성 스킬, README 생성 스킬, 위키 생성 스킬
모듈 6
옵시디언 위키 개발
⏱️ 2시간
Markdown 구조, 내부 링크, 태그, 폴더 구조, MOC, Graph View, 위키 자동 생성
모듈 7
통합 테스트와 개선
⏱️ 1시간
웹앱 실행 확인, 화면 이동, 입력폼 동작, 에이전트 UI, 스킬 문서, 위키 링크, README 정리
모듈 8
최종 발표와 피드백
⏱️ 1시간
MVP 시연, 에이전트·스킬·위키 구조 발표, 개선 로드맵, 실제 사업 적용 가능성
