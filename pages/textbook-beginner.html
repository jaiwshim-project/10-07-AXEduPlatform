모듈 1

대화형 ChatGPT 실습

기본 대화부터 프롬프트 엔지니어링까지

🎯 학습 목표

  • ChatGPT의 기본 인터페이스와 사용법 이해
  • 효과적인 프롬프트 작성 원칙 습득
  • 대화 컨텍스트 관리 방법 학습
  • 업무에 즉시 적용 가능한 프롬프트 패턴 익히기

💡 핵심 개념

1. ChatGPT란?

OpenAI가 개발한 대화형 AI 모델로, 자연스러운 대화를 통해 질문에 답하고, 문서를 작성하고, 문제를 해결합니다.

2. 좋은 프롬프트의 5가지 원칙

  • 명확성(Clear): 무엇을 원하는지 구체적으로 명시
  • 맥락(Context): 배경 정보와 목적 제공
  • 제약(Constraint): 형식, 길이, 톤 등 제한 조건 명시
  • 예시(Example): 원하는 결과물의 샘플 제시
  • 반복(Iterate): 결과를 보고 프롬프트 개선

🛠️ 실습 단계

실습 1: 첫 대화 시작하기

1
ChatGPT 접속

chat.openai.com에 접속하여 계정 생성 또는 로그인

2
기본 질문하기

"인공지능이란 무엇인가요?"라고 질문하고 응답 확인

3
후속 질문하기

"그럼 머신러닝과 딥러닝의 차이는 뭔가요?"로 대화 이어가기

4
대화 맥락 확인

ChatGPT가 이전 대화를 기억하는지 "좀 더 쉽게 설명해주세요"로 테스트

실습 2: 업무 이메일 작성

1
역할 부여

프롬프트 시작 부분에 "당신은 전문 비즈니스 작가입니다." 명시

2
상황 설명

이메일의 목적, 수신자, 톤 등 배경 정보 제공

3
제약 조건 명시

"3문단 이내, 공손하면서 간결한 톤"과 같은 조건 추가

4
결과 검토 및 수정

생성된 이메일을 검토하고 "더 친근한 톤으로 수정해주세요" 등으로 개선

📝 예제 프롬프트

예제 1: 회의록 요약
당신은 전문 회의 진행자입니다. 다음 회의 내용을 요약해주세요: - 핵심 결정사항 3가지 - 액션 아이템과 담당자 - 다음 회의 일정 [회의 내용 붙여넣기] 형식: 불릿 포인트, 각 항목은 1줄 이내
예제 2: 고객 응대 메시지
당신은 고객 서비스 전문가입니다. 상황: 제품 배송이 지연된 고객에게 사과 메시지 작성 톤: 진심 어린 사과 + 해결책 제시 길이: 2-3문단 포함 요소: - 사과 - 지연 사유 설명 - 보상 방안 - 예상 배송일
예제 3: 콘텐츠 아이디어 브레인스토밍
당신은 크리에이티브 디렉터입니다. 주제: [당신의 비즈니스/제품] 목적: 소셜 미디어 게시물 아이디어 10개 제안 타겟: [연령대, 관심사] 각 아이디어는: 1. 제목 (이모지 포함) 2. 핵심 메시지 1줄 3. 콜투액션 형식: 표 형태로 정리

✅ 체크리스트

ChatGPT 계정을 생성하고 기본 인터페이스 탐색 완료

이미지 생성형 ChatGPT

DALL-E 3로 시작하는 AI 이미지 생성

🎯 학습 목표

  • ChatGPT Plus의 DALL-E 3 이미지 생성 기능 이해
  • 효과적인 이미지 프롬프트 작성법 습득
  • 이미지 스타일, 구도, 분위기 제어 방법 학습
  • 비즈니스 용도의 이미지 제작 실습

💡 핵심 개념

1. DALL-E 3란?

OpenAI의 최신 이미지 생성 모델로, 텍스트 설명만으로 고품질 이미지를 생성합니다. ChatGPT Plus 구독 시 사용 가능합니다.

2. 이미지 프롬프트의 핵심 요소

  • 주제(Subject): 무엇을 그릴 것인가
  • 스타일(Style): 일러스트, 사진, 3D, 미니멀 등
  • 구도(Composition): 클로즈업, 와이드샷, 버드아이뷰 등
  • 색감(Color): 파스텔, 비비드, 모노톤 등
  • 분위기(Mood): 따뜻한, 차갑고 프로페셔널한 등
  • 디테일(Details): 배경, 조명, 질감 등

3. 이미지 사이즈 옵션

  • 정사각형: 1024×1024 (소셜 미디어 프로필)
  • 가로형: 1792×1024 (블로그 헤더, 프레젠테이션)
  • 세로형: 1024×1792 (모바일 화면, 포스터)

🛠️ 실습 단계

실습 1: 첫 이미지 생성하기

1
기본 프롬프트 작성

"A cozy coffee shop interior with warm lighting"으로 시작

2
결과 확인

생성된 이미지 확인 (약 30초 소요)

3
디테일 추가

"wooden furniture, plants, morning sunlight, minimalist design" 추가

4
변형 요청

"같은 장면을 evening mood로 다시 그려줘" 요청

실습 2: 비즈니스 용도 이미지 제작

1
용도 결정

블로그 썸네일, SNS 포스트, 프레젠테이션 등 목적 명확화

2
상세 프롬프트 작성

주제 + 스타일 + 구도 + 색감 + 분위기를 모두 포함

3
사이즈 지정

"가로로 긴 이미지로 만들어줘" 또는 "정사각형 이미지로" 명시

4
반복 개선

2-3번 반복하여 최적의 결과물 도출

📝 예제 프롬프트

예제 1: 블로그 썸네일 (기술 분야)
Create a wide horizontal image (1792×1024) for a tech blog thumbnail. Subject: A modern workspace with a laptop displaying code Style: Clean, minimalist, professional photography Colors: Blue and white dominant with orange accents Mood: Productive and innovative Details: Soft natural lighting, shallow depth of field, plant in background
예제 2: 소셜 미디어 포스트 (마케팅)
Generate a square image (1024×1024) for Instagram. Subject: A person holding a smartphone with notification icons floating around Style: Flat design illustration with gradient background Colors: Vibrant purple to blue gradient Mood: Engaging and modern Text space: Leave empty space at the top for text overlay
예제 3: 프레젠테이션 배경
Create a wide horizontal background image for a business presentation. Subject: Abstract geometric patterns representing data and connectivity Style: Modern minimalist with subtle 3D elements Colors: Navy blue, teal, and gold accents Mood: Professional and sophisticated Details: Not too busy, should work well as background for white text
예제 4: 이벤트 포스터
Design a vertical poster image (1024×1792). Subject: AI Education Workshop concept Style: Modern flat illustration with isometric elements Colors: Warm orange and cool teal combination Mood: Friendly, approachable, educational Details: Include symbolic elements like books, lightbulb, robot, laptop Composition: Leave space in center for event title text

✅ 체크리스트

ChatGPT Plus에서 DALL-E 3 이미지 생성 기능 활성화 확인
6가지 프롬프트 요소(주제, 스타일, 구도, 색감, 분위기, 디테일) 이해
3가지 사이즈(정사각형, 가로형, 세로형)로 각각 이미지 생성 완료
업무에 사용할 수 있는 이미지 최소 3개 제작
생성된 이미지 다운로드 및 저장 방법 숙지

프로젝트형 ChatGPT

Projects 기능으로 반복 작업 자동화하기

🎯 학습 목표

  • ChatGPT의 Projects 기능 이해 및 활용
  • 커스텀 지침(Custom Instructions) 설정 방법 학습
  • 파일 업로드 및 컨텍스트 관리 실습
  • 반복적인 업무를 자동화하는 프로젝트 템플릿 제작

💡 핵심 개념

1. Projects란?

ChatGPT Plus의 고급 기능으로, 특정 주제나 작업을 위한 독립적인 작업 공간을 만듭니다. 각 프로젝트는:

  • 자체 대화 히스토리
  • 커스텀 지침 (역할, 규칙, 형식)
  • 업로드된 파일 및 지식 베이스
  • 독립적인 컨텍스트

2. 커스텀 지침의 구조

  • 역할 정의: "당신은 ___입니다"
  • 작업 규칙: 항상 지켜야 할 원칙
  • 출력 형식: 결과물의 구조
  • 금지 사항: 하지 말아야 할 것

3. 프로젝트 활용 시나리오

  • 콘텐츠 제작 (블로그, 소셜 미디어)
  • 고객 응대 템플릿
  • 문서 번역 및 교정
  • 데이터 분석 및 리포트
  • 코드 리뷰 및 디버깅

🛠️ 실습 단계

실습 1: 첫 프로젝트 만들기

1
프로젝트 생성

좌측 사이드바에서 "New Project" 클릭

2
프로젝트 이름 설정

예: "블로그 포스트 작가", "고객 이메일 어시스턴트"

3
커스텀 지침 입력

프로젝트 설정에서 역할, 규칙, 형식 정의

4
테스트 대화

프로젝트 내에서 대화를 시작하고 지침이 적용되는지 확인

실습 2: 파일 기반 프로젝트

1
프로젝트 생성

"브랜드 가이드라인" 프로젝트 만들기

2
파일 업로드

브랜드 가이드 문서, 로고, 예시 콘텐츠 등 업로드

3
지침 설정

"업로드된 브랜드 가이드를 항상 참고하여 답변하세요" 추가

4
활용 테스트

"우리 브랜드 톤에 맞는 소셜 미디어 포스트 작성해줘" 요청

📝 예제 프로젝트 템플릿

템플릿 1: 블로그 포스트 작가
역할: 당신은 전문 블로그 콘텐츠 작가입니다. 규칙: 1. 모든 포스트는 SEO 최적화를 고려합니다 2. 도입-본문-결론 구조를 따릅니다 3. 단락은 3-4문장 이내로 짧게 유지합니다 4. 실용적인 예시와 액션 아이템을 포함합니다 출력 형식: # [제목] (H1) ## 도입 (H2) [문제 제기 및 독자의 관심 유발] ## 본문 (H2) ### 소제목 1 (H3) [내용] ### 소제목 2 (H3) [내용] ## 결론 (H2) [요약 및 행동 촉구] 톤: 친근하지만 전문적, 설명적이지만 간결함
템플릿 2: 고객 이메일 어시스턴트
역할: 당신은 고객 서비스 전문가입니다. 규칙: 1. 항상 고객의 이름으로 시작합니다 2. 문제를 정확히 이해했음을 확인합니다 3. 해결책을 명확히 제시합니다 4. 추가 지원 방법을 안내합니다 5. 긍정적인 마무리로 끝냅니다 출력 형식: [고객명]님, 안녕하세요. [문제 요약 및 공감] [해결책 제시] 1. [단계 1] 2. [단계 2] 3. [단계 3] [추가 안내] [긍정적 마무리] [서명] 톤: 공손하고 친절하며, 해결 지향적
템플릿 3: 데이터 분석 어시스턴트
역할: 당신은 데이터 분석가입니다. 규칙: 1. 업로드된 데이터 파일을 자동으로 분석합니다 2. 핵심 인사이트를 3-5개로 요약합니다 3. 시각화 가능한 데이터는 표로 정리합니다 4. 추가 분석이 필요한 영역을 제안합니다 출력 형식: ## 데이터 개요 - 총 레코드 수: - 기간: - 주요 변수: ## 핵심 인사이트 1. [인사이트 1] 2. [인사이트 2] 3. [인사이트 3] ## 주요 통계 [표 형태] ## 추천 액션 1. [액션 1] 2. [액션 2] 톤: 객관적이고 데이터 기반, 실행 가능한 제안

💼 실무 활용 팁

1. 프로젝트 명명 규칙

  • 목적이 명확한 이름 사용: "고객 응대", "콘텐츠 제작", "데이터 분석"
  • 팀원과 공유 시 이해하기 쉬운 이름 선택

2. 파일 관리

  • 최대 10개 파일, 총 512MB까지 업로드 가능
  • PDF, DOCX, TXT, CSV, JSON 등 지원
  • 정기적으로 오래된 파일 정리

3. 효율적인 사용법

  • 유사한 작업은 하나의 프로젝트로 통합
  • 자주 사용하는 프로젝트는 즐겨찾기
  • 대화 히스토리가 길어지면 새 대화 시작

✅ 체크리스트

최소 2개의 프로젝트 생성 완료
각 프로젝트에 커스텀 지침 설정
파일 업로드 및 활용 테스트 완료
실제 업무에 적용 가능한 프로젝트 템플릿 1개 제작
프로젝트 간 전환 및 관리 방법 숙지

Gemini 딥리서치

Google의 AI로 심층 조사 및 분석하기

🎯 학습 목표

  • Google Gemini의 특징 및 강점 이해
  • 실시간 웹 검색 기능 활용법 습득
  • 긴 문서 분석 및 요약 실습
  • 멀티모달 입력(텍스트 + 이미지) 활용

💡 핵심 개념

1. Gemini의 특징

  • 실시간 웹 검색: Google 검색 엔진과 통합되어 최신 정보 제공
  • 긴 컨텍스트: 최대 100만 토큰까지 처리 가능 (약 700페이지 분량)
  • 멀티모달: 텍스트, 이미지, 동영상 동시 분석
  • 다국어 지원: 한국어 포함 100개 이상 언어

2. ChatGPT vs Gemini 비교

💡 핵심 개념

1. 나노바나나란?

클라우드 기반 AI 이미지 생성 플랫폼으로, Stable Diffusion, DALL-E 등 다양한 모델을 API로 제공합니다. 개발자가 아니어도 웹 인터페이스로 쉽게 사용할 수 있습니다.

2. 주요 기능

  • Text-to-Image: 텍스트 설명으로 이미지 생성
  • Image-to-Image: 기존 이미지를 변형
  • Inpainting: 이미지의 일부만 수정
  • Outpainting: 이미지 영역 확장
  • ControlNet: 구도 제어

3. 인기 모델

  • Stable Diffusion XL: 고품질 일반 이미지
  • Realistic Vision: 사실적인 사진
  • Anime: 애니메이션 스타일
  • Midjourney-style: 예술적 이미지

4. 프롬프트 작성 팁

  • 긍정 프롬프트: 원하는 것을 상세히 기술
  • 부정 프롬프트: 피하고 싶은 요소 명시
  • 가중치: (keyword:1.5)로 강조, (keyword:0.5)로 약화
  • 품질 키워드: "masterpiece, best quality, high resolution"

💡 핵심 개념

1. NotebookLM이란?

Google이 개발한 AI 기반 연구 및 학습 도구입니다. 여러 문서를 업로드하면 AI가 내용을 분석하고, 질문에 답하고, 요약하며, 심지어 팟캐스트 형식의 오디오까지 생성합니다.

2. 주요 기능

  • 소스 추가: PDF, DOCX, TXT, 웹페이지, YouTube 등
  • AI 채팅: 업로드한 문서 기반 질의응답
  • 자동 요약: 핵심 내용, 개요, 타임라인 생성
  • Audio Overview: 두 명의 AI 호스트가 대화하는 팟캐스트 생성
  • 인용 추적: 모든 답변에 출처 표시

3. NotebookLM vs 다른 AI

  • 차별점: 업로드한 문서만을 기반으로 답변 (환각 최소화)
  • 장점: 정확한 출처, 신뢰할 수 있는 정보
  • 활용: 연구, 학습, 콘텐츠 제작, 지식 관리

4. Audio Overview의 특징

  • 자동으로 2명의 호스트 대화 형식 생성
  • 약 5-15분 분량의 팟캐스트
  • 자연스러운 톤과 억양
  • 복잡한 개념을 쉽게 설명
  • 무료로 생성 및 다운로드 가능

시나리오 3: 회의록 정리
상황: 여러 회의의 녹취록과 문서를 정리해야 함 NotebookLM 활용: 1. 회의록 TXT 파일 모두 업로드 2. "각 회의의 핵심 결정사항과 액션 아이템을 정리해줘" 요청 3. "담당자별로 할 일을 그룹핑해줘" 추가 질문 4. Audio Overview로 요약본 팀원들에게 공유 효과: 통합 정리, 놓친 부분 없이 관리
시나리오 4: 교육 콘텐츠 제작
상황: 신입 직원 교육 자료를 만들어야 함 NotebookLM 활용: 1. 사내 매뉴얼, 가이드라인 문서 업로드 2. "초보자도 이해할 수 있게 단계별로 설명해줘" 요청 3. FAQ 형태로 Q&A 생성 4. Audio Overview로 온보딩 팟캐스트 제작 효과: 자동화된 교육 콘텐츠, 일관된 정보 전달

💼 실무 활용 팁

1. 효과적인 소스 구성

  • 관련성 높은 문서만 추가 (최대 20개 제한)
  • 다양한 형식 혼합 (논문, 블로그, 동영상 등)
  • 시간 순서대로 정리하면 Timeline 기능 유용

2. AI 채팅 활용 팁

  • 구체적인 질문: "3페이지의 통계 수치 요약해줘"
  • 비교 질문: "문서 A와 문서 B의 관점 차이는?"
  • 형식 지정: "표로 정리해줘", "불릿 포인트로"

3. Audio Overview 최적화

  • 최소 1개, 이상적으로 3-5개 소스 권장
  • 너무 짧거나 긴 문서보다 중간 길이가 적합
  • 전문 용어가 많으면 AI가 설명하는 시간 증가

4. 노트북 관리

  • 주제별로 노트북 분리 (마케팅, 개발, HR 등)
  • 프로젝트별로 구분하여 컨텍스트 혼선 방지
  • 완료된 프로젝트는 아카이브
