📋 상세 시간표 (총 30시간)

시간 교육 목적 교육 내용 교육 결과물
Day 1: AI 플랫폼 아키텍처와 서비스 기획
1시간 AI 플랫폼 아키텍처 이해 AI Native 앱 vs AI Enhanced 앱, RAG vs Fine-tuning, 멀티에이전트 패턴, 기술 스택 분석 아키텍처 유형 정리표
2시간 서비스 기획 문제 정의, 타겟 고객, 핵심 가치, 사용자 여정, 기능 우선순위, MVP 범위 서비스 기획서, User Journey Map
2시간 기술 스택 선정 프론트엔드, 백엔드, DB, AI 모델, 배포 인프라, 모니터링 도구 선정 기술 스택 문서, ADR
1시간 실습 및 발표 플랫폼 기획서 작성, 발표 준비, 피드백 1차 플랫폼 기획서
Day 2: Claude Code 풀스택 플랫폼 고도화
2시간 인증/권한 시스템 회원가입, 로그인, JWT, RBAC, 세션 관리, 비밀번호 정책 Auth 시스템 구현
2시간 결제 연동 Stripe/Portone 연동, 요금제 설계, 구독 관리, Webhook 처리 결제 시스템 통합
2시간 관리자 대시보드 사용자 관리, 사용량 모니터링, 요금제 변경, API 로그 조회 Admin Dashboard
Day 3: RAG 지식베이스와 멀티에이전트 설계
2시간 RAG 아키텍처 RAG 개념, Vector DB (Pinecone/Supabase pgvector), 임베딩 모델, 검색 전략 RAG 설계 문서
2시간 청크 전략과 검색 문서 분할, 메타데이터, Hybrid Search, Reranking, Context Window 최적화 RAG 파이프라인 구현
2시간 멀티에이전트 설계 Agent 역할 분리, Orchestration 패턴, Workflow 설계, 병렬/순차 실행 Multi-agent 시스템
Day 4: MCP · 스킬 · 훅 · 옵시디언 위키 통합
2시간 MCP 서버 개발 MCP 프로토콜 이해, 커스텀 MCP 서버 개발, Tool 등록, Claude Code 연동 MCP 서버 구현
2시간 커스텀 스킬과 훅 SKILL.md 작성, Pre-commit 훅, CI/CD 자동화, 코드 품질 검증 자동화 파이프라인
2시간 옵시디언 위키 고급 플러그인 연동, Dataview 쿼리, Templater, Graph View 최적화, 자동 백링크 고급 위키 시스템
Day 5: 배포 · 운영 · 수익화 · 최종 발표
2시간 프로덕션 배포 Vercel/AWS 배포, 환경 변수 관리, HTTPS, 커스텀 도메인, CDN 설정 운영 환경 구축
1.5시간 모니터링과 운영 로그 분석, 에러 추적 (Sentry), 성능 모니터링, 사용량 분석, 알림 설정 모니터링 대시보드
1.5시간 SaaS 사업화 전략 요금제 설계, GTM 전략, 고객 획득, 수익화 모델, 성장 지표 (AARRR) 사업 계획서
1시간 최종 발표 플랫폼 데모, 아키텍처 설명, 사업 피칭, Q&A, 피드백 피칭 덱, 발표 자료
