🌟 바이브코딩이란?

Vibe Coding (바이브 코딩)은 전통적인 코딩 문법을 외우지 않고, 자연어 지시만으로 AI에게 프로그래밍을 시키는 새로운 개발 방식입니다. "이런 느낌(Vibe)으로 만들어줘"라고 말하면 AI가 코드를 작성하고, 개발자는 의도·검수·방향만 제시합니다.

📋 교육 내용

  • 클로드코드 (Claude Code) 소개
    • CLI 기반 AI 개발 도구
    • 터미널에서 자연어 명령으로 코드 생성
    • 파일 읽기·쓰기·수정 자동화
    • Git 통합, 버전 관리 자동화
    • 특징: 가볍고 빠른 기동전 (몽고 기마병의 마구)
  • 코덱스 (Codex) 소개
    • 심재우 대표가 개발한 바이브코딩 전용 도구
    • 웹 기반 인터페이스
    • 프롬프트 템플릿 내장
    • 단계별 가이드 제공
    • 특징: 완비된 중무장 (유럽 기사의 마구)
  • 바이브코딩 실습 프로젝트
    • 목표: 간단한 매뉴얼 사이트 개발
    • 구성: HTML + CSS + JavaScript
    • 기능: 네비게이션, 섹션, 이미지, 반응형 디자인
    • 자연어 지시로 전체 개발 과정 체험
  • 바이브코딩의 개발 흐름
    • 1단계: 의도 정의 — "이런 사이트를 만들고 싶어"
    • 2단계: AI가 코드 생성 — HTML/CSS/JS 자동 생성
    • 3단계: 검수 및 수정 — "이 부분을 이렇게 바꿔줘"
    • 4단계: 반복 개선 — 대화형으로 완성도 높이기
  • 클로드코드 vs 코덱스 비교
    • 속도: 클로드코드 > 코덱스
    • 진입장벽: 코덱스 < 클로드코드
    • 유연성: 클로드코드 > 코덱스
    • 가이드: 코덱스 > 클로드코드
    • 추천: 초보자는 코덱스, 숙련자는 클로드코드
