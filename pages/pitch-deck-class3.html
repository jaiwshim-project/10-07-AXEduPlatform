    실습 중 어려웠던 점, 업무 적용 방안에 대한 질의응답

💬 ChatGPT 개요

대화형 AI의 대표주자 — 범용 업무 처리 특화

  • 대화형 모드 — 질문과 답변, 브레인스토밍, 아이디어 생성
  • 이미지 생성 — DALL-E 통합, 텍스트로 이미지 생성
  • 프로젝트 모드 — 파일 업로드, 장기 대화 유지, 맥락 기억
  • GPTs (커스텀 봇) — 특정 목적에 맞게 커스터마이징한 나만의 AI 어시스턴트
    예: 마케팅 전문 GPT, 코딩 헬퍼 GPT, 영어 튜터 GPT
  • 주요 강점 — 범용성, 자연스러운 대화, 창의적 아이디어
  • 제한사항 — 실시간 검색 불가, 2023년 4월까지 학습 데이터

💡 추천 용도: 문서 작성, 이메일, 번역, 요약, 브레인스토밍, GPTs 활용

🎯 프롬프트 엔지니어링 5원칙

  • ① 명확한 지시 — 구체적 역할, 목표, 제약조건 제시
    "당신은 마케팅 전문가입니다. 신제품 출시를 위한 SNS 홍보 문구 3개를 100자 이내로 작성해주세요."
  • ② 맥락 제공 — 배경 정보와 예시 포함
    "우리 회사는 친환경 화장품을 판매합니다. 타겟은 20~30대 여성입니다."
  • ③ 단계적 요청 — 복잡한 작업을 여러 단계로 분해
    "먼저 키워드를 추출하고, 그 다음 구조를 잡고, 마지막으로 본문을 작성해주세요."
  • ④ 출력 형식 지정 — 표, 목록, JSON 등 구조화
    "결과를 표 형식으로 정리해주세요. 열은 제목, 내용, 우선순위입니다."
  • ⑤ 반복 개선 — 피드백 루프 활용
    "좋아요. 이제 좀 더 친근한 말투로 바꿔주세요."

💻 ChatGPT 실습 예제

예제 1: 업무 이메일 작성

프롬프트:
"당신은 프로젝트 매니저입니다. 개발 일정이 2주 지연되었습니다. 클라이언트에게 상황을 설명하고 대안을 제시하는 이메일을 정중한 톤으로 작성해주세요."

🤖 예제 3: GPTs 활용

실습 순서:
1. ChatGPT 접속 → 좌측 "Explore GPTs" 클릭
2. 검색창에 "마케팅" 입력
3. "Marketing Expert GPT" 선택
4. 프롬프트: "신제품 출시를 위한 SNS 홍보 전략 3가지를 제안해주세요"
5. 결과 확인 및 나만의 GPTs 제작 방법 확인

🔍 Gemini 개요

Google의 멀티모달 AI — 실시간 웹 검색 + 긴 문서 분석 특화

  • 실시간 웹 검색 — 최신 정보 자동 수집 (뉴스, 주가, 날씨 등)
  • 2M 토큰 컨텍스트 — 책 한 권(500페이지) 전체 분석 가능
  • 멀티모달 처리 — 텍스트 + 이미지 + 동영상 + PDF 동시 분석
  • YouTube 통합 — 영상 URL 입력 시 자동 요약
  • 주요 강점 — 최신 정보, 긴 문서, 멀티미디어 분석
  • 제한사항 — 창의적 글쓰기는 ChatGPT 대비 약함

💡 추천 용도: 시장 조사, 경쟁사 분석, 논문 요약, 최신 트렌드 리서치

🔬 Gemini 딥리서치 기능

🌐 실시간 웹 검색

최신 뉴스, 주가, 날씨, 트렌드를 자동으로 검색하여 답변에 포함

예: "오늘 삼성전자 주가는?" → 실시간 검색 후 답변

📄 긴 문서 분석

최대 2M 토큰 (약 150만 단어) 처리 가능. 책 한 권을 통째로 업로드 가능

예: 500페이지 논문을 10줄로 요약

🎥 멀티모달 처리

텍스트 + 이미지 + 동영상 + PDF를 동시에 업로드하여 통합 분석

예: 사진 속 제품을 분석하고 경쟁사 제품과 비교

📺 YouTube 요약

YouTube URL 입력 시 영상 내용을 자동 요약 (자막 기반)

예: 1시간 강의 영상을 5분 요약

🎙️ NotebookLM 개요

Google의 지식베이스 AI — 문서 기반 Q&A + AI 팟캐스트 생성

  • 지식베이스 구축 — 문서 최대 50개 업로드하여 통합 Q&A
  • Audio Overview — 2명의 AI가 대화하는 팟캐스트 자동 생성 (10~20분)
  • FAQ 자동 생성 — 업로드한 문서 기반 질문-답변 자동 추출
  • 인용 출처 명시 — 답변 시 원본 문서의 어느 부분인지 명시
  • 주요 강점 — 사내 문서 관리, 온보딩, 교육 자료 Q&A
  • 제한사항 — 업로드한 문서 외 정보는 답변 불가

💡 추천 용도: 지식 관리, 온보딩 가이드, 제품 매뉴얼, 팟캐스트 제작

🔧 NotebookLM 핵심 기능

📚 문서 업로드 (최대 50개)

PDF, DOCX, TXT, Google Docs 등 다양한 형식 지원

예: 회사 규정 10개 + 제품 매뉴얼 5개 업로드

❓ 지식베이스 Q&A

업로드한 문서 내용을 기반으로 질문에 답변. 출처 페이지 명시

예: "연차 사용 규정은?" → 3번 문서 12페이지 인용

🎙️ Audio Overview (팟캐스트)

2명의 AI가 업로드한 문서 내용을 대화 형식으로 설명 (10~20분 음성)

예: 제품 매뉴얼을 듣기 쉬운 팟캐스트로 변환

📝 FAQ 자동 생성

문서에서 중요한 질문-답변을 자동 추출

예: 사내 규정 10개 문서 → FAQ 30개 자동 생성
